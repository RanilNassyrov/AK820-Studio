# Наша доработка прошивки

Прошивка [jdlien/qmk_firmware](https://github.com/jdlien/qmk_firmware) (GPL-2.0, ветка `ak820pro-jdlien`) плюс `host-colors.patch`: raw HID канал 0x14 и эффект HOST_COLORS, цвет каждой клавиши с компьютера. Наш код прошивки распространяется под той же лицензией.

Сборка идёт в контейнере QMK тем же компилятором, что у автора: `build-firmware.ps1` в этой папке, нужен Docker Desktop. Готовый файл появляется здесь же.

Цвета с компьютера: `[0x07, 0x14, первый светодиод, количество до 9, r, g, b, ...]`, эффект номер 17.

Канал 0x15: `[0x07, 0x15, 1, первый]` читает цвета светодиодов, `[0x07, 0x15, 2, первый, количество до 9, r, g, b, ...]` задаёт палитру эффекта 11, `[0x07, 0x15, 3]` сохраняет её во внешнюю флеш-память (0xFF0000).

Что ещё меняет патч: окно ШИМ подсветки стало вчетверо длиннее (1,2 МГц вместо 4,8 МГц, светодиоды горят около 46% времени вместо 17%), скорости и яркость эффектов, новые эффекты 10-16, раскладка по надписям на клавишах, первый экран меню с эффектами и цветом, GIF на экране идёт со временем каждого кадра из заголовка (единица 2 мс, 0 значит 100 мс) вместо постоянных 10 кадров в секунду.
